Ringkasan

Aplikasi web khusus untuk usaha Anda (kasir, booking, stok, akuntansi, pajak) yang bisa jalan offline di PC atau online. Semua angka di halaman ini adalah harga mulai; saya kunci harga final di penawaran tertulis setelah scope jelas.

Fitur yang Anda dapat

  • Aplikasi web sesuai alur usaha Anda, bukan sekadar ubah tema
  • Bisa jalan di PC Windows, server lokal, atau online
  • Tampil rapi di HP: kasir, booking, gudang, atau dashboard owner
  • Master data, transaksi, laporan, dan hak akses per peran
  • Export PDF/Excel, struk, dan nomor dokumen yang rapi
  • Bahasa Indonesia (bisa plus Inggris bila perlu)
  • Source code diserahkan; tidak ada biaya lisensi berulang untuk aplikasinya
  • Hosting dan domain dihitung terpisah per bulan, hanya jika Anda ingin saya yang kelola

Pertanyaan singkat

Apakah harga di halaman ini sudah final?

Belum. Angka di situs adalah harga mulai. Harga final saya kirim lewat penawaran tertulis setelah ruang lingkup (scope) disepakati.

Bagaimana cara mulai?

Cukup DM saya di Threads untuk konsultasi gratis. Setelah kebutuhan jelas, saya buatkan ringkasan scope dan penawaran tertulis.

Apa yang termasuk support 3 bulan?

Perbaikan bug dari pekerjaan yang sudah diserahkan, pertanyaan pemakaian, dan penyesuaian kecil. Perubahan lingkup baru dihitung terpisah.

Apakah ada biaya langganan bulanan?

Untuk pengerjaan jasa, tidak ada biaya langganan. Support ringan 3 bulan sudah termasuk. Maintenance tahunan bersifat opsional, sekitar 15–20% per tahun. Untuk aplikasi custom, biaya hosting dihitung terpisah jika Anda ingin saya yang kelola.

Saya lihat sudah ada YA Florist, YA Salon, YA Toko. Harus custom?

Tidak selalu. Kalau alurnya dekat dengan produk siap pakai, saya sarankan mulai dari situ. Custom dibuat kalau prosesnya memang beda atau perlu gabungan yang belum ada.

Mau bahas kebutuhan Anda?

Konsultasi gratis. Cukup DM saya di Threads. Saya balas dengan pertanyaan ringkas, lalu penawaran tertulis bila lingkupnya sudah jelas.
