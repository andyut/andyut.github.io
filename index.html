au_query

YA Smart Query Reports

Simpan query SQL sekali, jalankan kapan saja dari Odoo ke database SAP Business One (atau PostgreSQL) di satu atau banyak perusahaan.

  • Katalog query tersimpan dengan parameter tanggal dan 4 parameter bebas
  • Jalan di beberapa database perusahaan sekaligus, hasilnya digabung
  • Output TXT, CSV, Excel, PDF, JSON, dan template HTML/Jinja2
  • Sudah ada contoh query siap pakai untuk SAP B1 dan Odoo

Tentang

Tentang Saya

Halo, saya Yohanes Andy, developer ERP di Indonesia. Sehari-hari saya ngurusin Odoo dan SAP Business One di perusahaan distribusi, manufaktur, dan FnB (Meatshop, Resto, Manufaktur): implementasi, bikin modul custom, laporan, sampai integrasi dua sistem lewat SAP Service Layer dan SQL.

Dari pengalaman itu saya bikin aplikasi siap pakai dengan brand YA Consulting: modul Odoo 18 yang sudah terbit di Odoo Apps Store, dan aplikasi web standalone untuk UMKM yang belum butuh ERP penuh. Fokus saya sederhana: aplikasinya harus gampang dipakai, laporannya keluar, dan datanya aman.

  • Odoo 18 (Community & Enterprise): modul custom, laporan PDF/Excel, multi-company
  • SAP Business One: Service Layer, query SQL Server, laporan & integrasi ke Odoo
  • Aplikasi web custom: ringan, bisa jalan di PC Windows, server lokal, atau online
  • FnB (Meatshop, Resto, Manufaktur): multi company, multi outlet, laporan & transaksi konsolidasi
  • Pajak Indonesia: e-Faktur Coretax 2025
